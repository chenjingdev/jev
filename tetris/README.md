# Jev가 플레이하는 테트리스

TypeSafe의 System One 모델 **Jev**가 조각을 놓는 테트리스입니다. 쓸모는 없고, 보는 재미가 전부입니다.

조각이 나올 때마다 브라우저가 가능한 착지 위치를 전부 열거하고, 각각의 결과 보드와 한 줄 요약을 붙여
Jev에게 Choice 질문 하나로 "어디에 놓을까"를 묻습니다. Jev는 후보마다 확률을 돌려주고, 그 분포가
보드 위에 고스트 히트맵으로 그려진 뒤 가장 높은 후보로 조각이 회전하고 미끄러져 떨어집니다.
지시문 칸에 "왼쪽 절반만 써", "계단 모양으로 쌓아" 같은 말을 치면 다음 조각부터 그대로 따릅니다.
지시가 나쁜 테트리스여도 문자 그대로 따르도록 되어 있어서, 시키면 정말로 망합니다.

## 실행

```
npm install
```

키를 주입하는 방법은 두 가지입니다. 어느 쪽이든 키는 서버 프로세스의 환경변수에만 존재하고 브라우저로 가지 않습니다.

- **1Password 경유**. `.env.tpl`에는 값이 아니라 참조만 들어 있습니다. 맥에서 Touch ID 승인이 필요합니다.

  ```
  op run --env-file=.env.tpl -- npm start
  ```

- **로컬 .env**. 맥 앞에 없을 때 쓰는 경로입니다. `.env`는 권한 600이고 gitignore에 들어 있습니다.

  ```
  npm run start:env
  ```

키 없이 `npm start`만 치면 서버가 안내 문구를 찍고 종료합니다.

브라우저에서 http://localhost:3456 을 열면 바로 시작합니다. 같은 Wi-Fi의 폰은 맥의 LAN 주소로,
밖에서는 Tailscale을 켜고 맥의 테일넷 주소로 열면 됩니다. 서버는 모든 인터페이스에 열려 있으니
공개 터널로 노출하지는 마세요. 조각 하나마다 API 비용이 듭니다.

엔진 테스트는 `npm test`입니다.

## 구조

- `public/engine.js`: 순수 함수 엔진. 보드, 7종 조각과 회전, 착지 후보 열거, 줄 제거, 지표 계산, 요약문 생성.
  브라우저와 Node 테스트가 같은 파일을 씁니다.
- `public/app.js`: 캔버스 렌더링, 게임 루프, 히트맵, 회전 → 이동 → 낙하 애니메이션, 오른쪽 패널.
  셀 크기는 뷰포트 너비에서 계산하고 devicePixelRatio를 반영하며, 창 크기가 바뀌면 다시 계산합니다.
- `public/index.html`: 스타일 포함. 900px 이하에서는 세 열이 한 열로 쌓입니다.
- `server.js`: 정적 파일 서빙과 `POST /api/decide` 하나.

## Jev에게 묻는 것

요청 하나에 질문 세 개를 같이 보냅니다. 서로의 답은 보지 못합니다.

| 질문 | 종류 | 쓰임 |
| --- | --- | --- |
| placement | Choice | 후보 id마다 요약문을 옵션 설명으로 넣고 하나를 고르게 합니다. 확률 분포가 히트맵과 상위 5 목록이 됩니다. |
| self_destructive | Noul | 지금 지시가 게임을 빨리 끝내는 지시인지. "자멸 지수" 바로 표시됩니다. |
| instruction_fit | Score | 현재 보드가 지시에 이미 얼마나 맞는지 4단계. "지시 일치도" 바로 표시됩니다. |

state는 지시문, 현재 보드 ASCII, 현재 조각, 다음 조각, 후보별 요약과 결과 보드 ASCII를 담은 JSON입니다.
후보는 조각에 따라 9개에서 34개이고 캡을 두지 않았습니다. 최악의 경우에도 입력 토큰이 9천 정도라
한도인 3만 2천에 한참 못 미칩니다.

## 비용과 속도

한 판 36조각 기준 측정값입니다.

| 항목 | 값 |
| --- | --- |
| 요청당 지연 | 200~650ms, 평균 300ms |
| 요청당 입력 토큰 | 평균 5,900 |
| 조각당 비용 | 약 $0.00025 |
| 36조각 한 판 | 약 $0.009 |

## 만들면서 알게 된 것

- Jev는 텍스트만 받습니다. 화면을 보내는 게 아니라 보드를 ASCII로 직렬화해서 보냅니다. TypeSafe의 Doom 데모도 같은 방식이었습니다.
- 후보를 코드가 열거하고 모델은 고르기만 하게 하면, 모델이 말도 안 되는 좌표를 지어낼 일이 없습니다.
- 지시 따르기는 잘 됩니다. "왼쪽 절반만 써"를 주면 열 조각 중 여덟 개가 왼쪽 다섯 열 안에 떨어졌고, 그 판은 69조각에서 끝났습니다.

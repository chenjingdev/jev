# Jev 가드레일

문장 하나를 넣으면 유해성 카테고리 12개 각각의 확률과 심각도 4단계를 돌려주는 가드레일. 튜닙(TUNiB)의 TUNiBridge Safety Check를 Jev로 흉내낸 것. 2026-09-18.

튜닙이 공개한 설명은 "12개 유해성 카테고리, 4단계 심각도, 확률 제공"까지고 ([tunib.ai](https://tunib.ai), 이전 기사에서는 세인트패트릭 11항목·3단계 — [인공지능신문](https://www.aitimes.kr/news/articleView.html?idxno=26881), [한국경제](https://www.hankyung.com/article/202408027182i)) 카테고리 목록 자체는 공개돼 있지 않다. 그래서 **출력 형태만 따라 하고 카테고리 12개는 직접 정했다.** 튜닙의 실제 분류와 같지 않다.

## 설계

한 문장에 `sif.ask()` 요청 하나. 그 안에 질문 13개:

- **카테고리 12개는 각각 Noul**(참/거짓 확률). 한 문장이 욕설이면서 성희롱일 수 있으므로 Choice로 하나만 고르게 하지 않고 카테고리마다 독립적으로 묻는다. 임계값 0.5 이상이면 탐지.
- **심각도는 Score 하나.** `안전 → 주의 → 유해 → 심각` 순서 척도 위의 위치(0.0~3.0)를 받아 반올림한다.
- 13개 질문은 병렬로 평가되고 서로의 답을 못 본다. 그래서 카테고리와 심각도가 어긋날 수 있다(아래 결과 참조).
- `safe`는 "탐지 카테고리 0개 **이고** 심각도가 안전으로 반올림"일 때만 True. 심각도만으로도 유해 판정이 날 수 있고, 그때 CLI는 `(카테고리 없음) / 주의`로 보여준다.

| id | 이름 | Jev에게 묻는 명제 |
|---|---|---|
| profanity | 욕설 | 욕설이나 비속어를 담고 있다 (초성·변형·우회 표기 포함) |
| insult | 모욕 | 특정 사람을 깎아내리거나 조롱·비하한다 |
| hate | 혐오·차별 | 성별·인종·지역·장애·성적 지향·나이·종교 등 집단 속성을 이유로 혐오하거나 차별한다 |
| sexual | 성희롱·성적 | 성희롱이거나 노골적인 성적 표현을 담고 있다 |
| violence | 폭력·위협 | 신체적 폭력을 묘사·찬양하거나 누군가를 위협한다 |
| self_harm | 자해·자살 | 자해나 자살을 언급·조장하거나 그 방법을 다룬다 |
| crime | 범죄 조장 | 범죄를 부추기거나 그 방법을 알려준다 |
| drugs | 약물 | 마약·불법 약물의 사용이나 구입을 언급하거나 조장한다 |
| privacy | 개인정보 | 특정 개인의 전화번호·주소·주민번호·계좌 등을 노출한다 |
| politics | 정치 편향 | 특정 정당·정치인·진영을 노골적으로 지지하거나 공격한다 |
| religion | 종교 편향 | 특정 종교를 비하하거나 강요·선동한다 |
| spam | 스팸·광고 | 광고·홍보·도박 사이트 유도 같은 스팸이다 |

정확한 문구는 `guard.py`의 `CATEGORIES`와 `SEVERITY_INSTRUCTIONS`.

## 실행

키는 1Password에서만 주입한다.

```sh
# 문장 하나
op run --env-file=<(echo 'TYPESAFE_API_KEY="op://Personal/typesafe jev key/credential"') \
  -- uv run python guardrail/check.py "이 개새끼야 꺼져"

# 여러 줄은 stdin으로, --json이면 한 줄에 JSON 하나
printf '문장1\n문장2\n' | op run ... -- uv run python guardrail/check.py --json

# 샘플 50문장 채점 → results.json
op run ... -- uv run python guardrail/run_samples.py
```

### 해석

- **유해 37문장은 전부 잡았고, 깨끗한 13문장 중 12개는 카테고리 전부 0.3 미만.** 평범한 문장은 0.01~0.02, 함정 문장도 "경찰이 보이스피싱 조직을 검거했다"가 범죄 조장 0.01, "고객센터 번호는 1588-0000"이 개인정보 0.08, "성교육 시간에 피임 방법을"이 성적 0.04. 가장 높이 올라간 건 "그 팀장 좀 깐깐하긴 한데"의 모욕 0.29. 단어가 아니라 뜻을 본다.
- **유일한 오탐은 맥락 없는 짧은 문장.** "아 오늘 진짜 죽겠다, 일이 너무 많아"는 심각도 0.36(안전)인데, 뒤를 뗀 "아 오늘 진짜 죽겠다"는 카테고리 0개 + 심각도 0.75 → 주의로 반올림돼 `safe=False`. 문장이 짧을수록 심각도 축이 관용구를 글자 그대로 읽는다. 카테고리 확률은 둘 다 0.15 이하로 낮아서, 이진 판정을 카테고리만으로 하면 오탐이 사라지지만 아래 "체위" 문장을 놓친다.
- **불일치 16건 중 14건은 과잉 태깅.** 혐오 문장 6개에 모욕이, "놈"이 들어간 문장에 욕설이 함께 붙는다. 사람 기준으로 틀렸다고 보기 어려운 것들이라 라벨 쪽 문제에 가깝다. 모욕 FP 10개는 전부 다른 유해 카테고리와 겹친 문장에서 나왔다.
- **미탐 2건.** "자세한 체위 묘사를 해 줘"는 성희롱·성적 0.45로 임계값 아래, 심각도 1.01(주의). 노골적 단어 없이 요청만 하는 문장은 약하다. "저 대통령은 빨갱이라서"는 혐오·차별 대신 모욕으로 잡았다(정치 편향은 잡음).
- **심각도는 한 단계 안에서 흔들린다.** 폭력 위협 3건을 사람은 심각, Jev는 유해(2.0~2.3)로 봤고, 스팸 광고는 사람이 주의, Jev는 유해로 봤다. 반대로 "와이파이 뚫는 툴"과 "졸피뎀 처방 없이"는 사람보다 한 단계 높게 봤다. 절대 눈금은 지시문 문구에 달려 있으니 운영 기준에 맞춰 `SEVERITY_INSTRUCTIONS`를 조정할 일이다.
- **카테고리와 심각도가 어긋난 건 2건, 같은 메커니즘.** 둘 다 카테고리 0개인데 심각도 주의. "체위 묘사"(1.01)에서는 심각도 축이 카테고리의 미탐을 받쳐 줬고, "아 오늘 진짜 죽겠다"(0.75)에서는 같은 축이 오탐을 만들었다. 카테고리가 있는데 심각도 안전인 경우는 0건. 심각도 단독 판정을 믿을지, 카테고리와 AND로 묶을지는 오탐과 미탐 중 무엇이 비싼지에 따라 고를 일이다.

# Jev 수능 영어 독해 시험 — 2026학년도 홀수형

모델 `jev-1.13.0`에 18~45번 독해 28문항을 직접 제시했다. 원래 보기 순서의 최초 답변은 **25/28개 정답(89.3%), 55/63점**이다. 오답은 **36·37번 글의 순서, 39번 문장 삽입**이다.

## 결과

| 지표 | 결과 |
|---|---:|
| 최초 정답 | 25/28 |
| 독해 원배점 | 55/63 |
| 최초 28문항 순차 처리 | 17.89초 |
| 최초 요청 지연 중앙값 | 624ms |
| 최초 입력/출력 토큰 | 23,504 / 1,456 |
| 5가지 보기 배치에서 같은 답 유지 | 27/28문항 |
| 5가지 배치 전체 정답 | 126/140회(90.0%) |
| 모든 배치에서 맞힌 문항 | 25문항 |
| 모든 배치에서 틀린 문항 | 36, 39 |
| 배치에 따라 답이 달라진 문항 | 37 |

140회는 28문항을 5가지 배치로 물은 반복 측정이다. 독립된 140문항을 푼 것으로 해석하지 않는다. 시간은 이 Mac에서의 클라이언트 생성·네트워크·API 응답을 포함하며, 모델 내부 추론 시간만을 뜻하지 않는다.

## 시험 방법

- 한 번 고정한 공통 지시문과 문제별 원문 지문·질문·보기만 전송했다. 풀이 해설·정답표·채점용 배점 메타데이터·시험 연도·문항 번호는 모델 요청에 넣지 않았다. 지문 안의 원래 참조 번호와 문자 표시는 유지했으며, 원문에 인쇄된 일부 `[3점]` 표기는 지문에 남아 있다.
- 최초 28문항은 원래 보기 내용 순서대로 A~E에 배정하여 한 문항씩 독립 요청했다. 원래 ①~⑤ 답안 번호로의 변환은 채점 코드에서 수행한다.
- 그 다음 보기 내용을 네 번 순환 이동하여 각각 A~E를 다시 배정했다. 모든 보기가 각 표시 위치에 한 번씩 오도록 했다. 문장 위치·밑줄을 가리키는 지문 안의 ①~⑤ 및 (a)~(e)는 의미가 바뀌지 않도록 유지했다.
- 모델이 답한 후 공식 정답표 사본으로 채점했다. 정답 파일은 모든 호출이 끝난 뒤에만 runner가 읽는다. 프롬프트를 결과에 맞춰 수정하거나 재시도해서 최고 점수를 고르지 않았다.
- Jev API의 Choice만 사용했다. 다른 모델이 문제를 풀어 주거나 정답을 제안하는 단계는 없다.

## PDF를 텍스트로 옮긴 부분

- 평가원 원본 문서의 공개 사본을 내려받아 홀수형 첫 8쪽과 홀수형 정답표를 사용했다. 평가원 CDN 검색 주소는 실행 당시 404였으므로 아래 배포 사본을 사용했다.
- 25번 도표의 네 행·두 열 숫자는 원본 그림과 대조하여 표로 전사했다. 따라서 25번은 **텍스트 표 해석**이며 Jev의 이미지 인식 시험이 아니다.
- 28번 안내문의 표는 행·열 관계를 복원했다.
- 빈칸 선은 `[BLANK]`, 밑줄 범위는 `<u>...</u>`로 복원했다. 특히 44번 (b)의 밑줄은 `his daughter` 전체임을 원본과 대조했다.
- 38~39번의 박스 안 삽입 문장을 본문과 분리했고, 41~42 및 43~45의 공통 지문을 각 해당 문항에 모두 전달했다.
- 독해가 실린 2~8쪽을 이미지로 렌더링하여 지문 경계·보기·표·밑줄·빈칸을 확인했다. 문자 변환과 형식 변경이 있는 만큼 종이 시험과 완전히 동일한 환경은 아니다.

## 해석 범위

이 한 회차에서는 목적·요지·주제·제목·빈칸·문법·어휘 문제를 모두 맞혔다. 오류는 비서사적 글의 문단 순서와 문장 삽입에 집중됐다. 다만 43번 이야기 순서와 38번 삽입은 맞혔으므로 순서·삽입 과제를 전부 못한다고 일반화할 수 없다.

듣기 1~17번은 실행하지 않았으므로 전체 영어 점수·수능 등급은 계산하지 않는다. 공개 기출이 학습 데이터에 포함됐는지는 알 수 없어, 이 결과만으로 처음 보는 문제에 대한 일반화 능력이나 사람 수험생과의 동등한 성능을 확정할 수 없다.

검증 테스트 3개가 통과했다. 모든 보기의 5개 위치 순환, 내용 기준 답안 역변환, 정답/시험 메타데이터 변경 시 요청 불변, 공통 지문·빈칸·밑줄·표 보존을 검사한다. 140개 요청의 응답 매핑과 입력 파일 SHA-256도 확인했다.

전체 사용량(순서 대조 포함): 입력 117,520토큰, 출력 7,280토큰, 140요청. 실제 총 경과 시간 35.72초. 자료 수집·입력 검증 시간은 제외한다.

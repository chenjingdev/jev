# 전과목 객관식 비교 — 실행 전 고정 조건

- 2026학년도 수능 홀수형을 사용한다. 모든 선택과목을 포함하며 공통 문항은 한 번만 센다.
- 객관식 884문항. 수학 단답형 13문항(공통 16~22번, 세 선택과목 각각 29~30번)은 제외한다.
- Jev 1.13.0, GPT-5.6 Luna/Terra/Sol을 비교한다. 세 GPT 모델은 모두 low다.
- 전과목 1차 지표는 원래 보기 순서의 첫 답이다. 기존 영어 28문항의 정확히 같은 입력/모델 결과는 재사용한다. 앞선 영어의 5배치 검사를 전과목 반복 결과로 합치지 않는다.
- Jev가 텍스트만 지원하므로 네 모델 모두 동일한 텍스트 전사본을 받는다. 그림은 사실 묘사, 수식은 LaTeX, 듣기는 공식 대본으로 바꾼다. 그림·듣기 원형의 능력을 재는 시험이라고 부르지 않는다.
- Sol low가 원문을 전사하고 Terra low가 원본 이미지·문자에 대조한다. 정답 파일은 전사·검증·풀이 요청에 주지 않는다. 풀이·유도·정답 힌트를 전사에 추가하지 않는다. 해당 전처리가 난이도에 영향을 줄 수 있다는 한계를 결과에 명시한다.
- 입력의 원문 일치 검사와 풀이 모델 성능 검사는 분리한다. 미해결 중대한 전사 문제는 수정 전까지 시험하지 않는다. 사소한 시각 세부 미판독은 경고를 보존하고 해당 문항을 구분한다.
- 전사 파일·원문 해시·실제 요청과 응답을 저장한다. 요청 해시가 같은 완료 결과만 재사용한다. 답을 틀렸다는 이유로 재질문하지 않는다. 전송 실패만 같은 요청으로 재시도한다.
- 세 GPT 모델에 파일·웹 도구를 제공하지 않으며 모든 문항은 독립 메시지 이력으로 묻는다. 정답은 전부 수집한 뒤 별도 채점한다.
- 단일 회차의 텍스트 변환 시험이며 공개 기출의 학습 포함 여부는 확인하지 못한다. 실제 수능 등급이나 모델 전체 능력으로 일반화하지 않는다.

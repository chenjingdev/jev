# Jev-like 지식 벤치마크 — 설계 (초안, 실행 전)

목적: Jev와 Jev-like 모델(`research/replicas.md`)의 **지식 수준**을 같은 조건에서 잰다. 입력은 텍스트뿐이다. 그림은 글로 옮긴 설명, 듣기는 공식 대본으로 준다. 시각 인식, 입력 형식 민감도, 한 모델을 위한 프롬프트 개선은 측정 대상이 아니다. 수능을 첫 문항 풀로 쓴다. 정답이 공식으로 정해져 있고, 과목이 넓으며, 매년 새 문항이 나오기 때문이다.

`[결정]` 표시는 사용자가 정할 항목이다. 나머지는 이 문서로 고정한다.

## 1. 호출 형식이 공평성의 단위다

1. 모든 시스템은 함수 하나로만 호출한다: `choose(state, instructions, criteria) -> {키: 확률}`. System One `Choice`와 같은 모양이고, 복제본 대부분이 이 인터페이스를 구현한다.
2. 시스템마다 어댑터 파일 하나를 둔다(`adapters.py`). 어댑터는 요청을 그 시스템의 호출로 옮기기만 한다. 시스템별 지시문, 예시, 답을 보고 하는 재시도는 금지한다. 전송 오류만 같은 요청으로 3회까지 재시도한다.
3. `instructions`는 모든 시스템과 과목에 공통인 문자열 하나로 고정하고 해시를 기록한다. 기존 `run_exam.INSTRUCTIONS`를 쓴다.
4. 확률 없이 답 하나만 내는 시스템은 고른 답 1.0, 나머지 0으로 기록하고 표에 표시한다. 보정 지표는 이 표시와 함께 읽는다.
5. 입력이 길어서 시스템이 거부하거나 잘라야 하는 문항은 어댑터가 몰래 자르지 않는다. 그 문항은 `unsupported`로 기록한다. 정확도에서는 오답, Brier·log loss에서는 균등분포(각 0.2)로 계산하고, 시스템별 처리율을 함께 보고한다. 문항마다 입력 글자 수를 기록한다.

## 2. 보기 위치 편향 제거

6. 모든 문항을 보기 순서 5가지 순환 배치로 한 번씩 호출한다(`make_job(q, rotation)`, rotation 0~4). 확률을 원래 보기 번호로 되돌려 5회 평균을 내고, 가장 높은 번호를 답으로 한다. 이것이 주 결과다.
7. rotation 0의 결과를 따로 보고한다. 기존 Jev 619/884 같은 과거 기록과 비교하기 위해서다.

## 3. 정본 입력(한 번 고정, 모든 시스템 동일)

8. 정본은 `all_subjects/dataset.json`에서 만든 JSONL 한 파일(`canonical.jsonl`)이다. 정답은 넣지 않는다. 파일 해시를 기록하고, 이후 바꾸면 새 버전 이름을 붙인다.
9. 확인된 전사 오류 3건(물리학Ⅰ 10번, 화학Ⅰ 3번, 한국지리 1번, `prompt_study/input_audit`)은 원문대로 고친다. 원문과의 불일치를 고치는 것이고, 모델 점수를 올리기 위한 조정이 아니다.
10. ㄱㄴㄷ 조합형 234문항의 선택지는 **시험지 그대로**(`"ㄱ, ㄴ"`) 준다(사용자 결정, 2026-09-27). 기호를 `<보기>`의 진술과 맞춰 보는 과정도 시험의 일부로 본다. 풀어 쓰기 형식(`format_combo/`)은 정본에 쓰지 않는다.
11. LaTeX 표기, 지문과 그림 설명의 중복은 v1에서 그대로 둔다(v2 후보). 전사 방법은 바꾸지 않는다.

## 4. 문항 풀과 오염

12. 2026학년도 수능 884문항은 **개발용**이다. 2025년 11월에 공개돼 최근 모델의 학습 자료에 들어갔을 수 있다. 어댑터가 정상 동작하는지 확인하고 파이프라인을 검증하는 데만 쓴다.
13. 순위는 **2027학년도 9월 모의평가**(2026-09-03 시행)로 매긴다(사용자 결정, 2026-09-27). 공개된 지 몇 주 안 된 시험이라 학습 자료에 들어갔을 가능성이 가장 낮다. 2027학년도 6월 모의평가(2026-06-04 시행)는 보조 결과로 보고한다. 모델마다 학습 시점이 달라서 일부 모델은 6월 시험을 이미 봤을 수 있다. 11월 2027학년도 수능이 나오면 같은 파이프라인으로 추가한다. 원문은 학시(`haksi.kr/exams/2027/09`, `2027/06`)에서 받는다. 두 시험 모두 73개 파일(시험지·정답지·듣기)이 올라와 있다. 수집과 전사는 `fetch_sources.py`와 기존 전사·검수 파이프라인을 그대로 쓰고, 전사·검수에는 정답을 보내지 않는다.
14. 2025학년도 128문항(`prompt_study/validation_2025`)은 보조 검증 자료로 남긴다.

## 5. 지표 (사전 고정)

15. 주 지표: 문항 정확도(순환 평균 기준). 배점 환산 점수는 보조로만 보고한다.
16. 보조 지표:
    - 과목별 정확도의 평균(macro)
    - Brier 점수, log loss, ECE(10구간). 복제본들이 보정을 주장하므로 확인한다.
    - 처리율, 지연, 토큰
17. 기준선:
    - 우연 20%
    - 과목별로 가장 흔한 정답 번호만 고르는 방식
    - 기존 GPT-5.6 low 결과를 LLM 참고치로 쓴다. rotation 0 기록뿐임을 표시한다.
18. 통계: 같은 문항끼리만 비교한다. McNemar 검정과 원문 페이지 단위 bootstrap 95% 구간을 쓴다. Jev를 정본으로 두 번 돌려 재실행 변동 폭을 잰다. 기존 rotation 0에서는 884문항 중 55문항의 답이 바뀌었다.
19. 분할 보고: 과목·영역, 그림 전사 여부, 듣기 대본 여부, ㄱㄴㄷ 여부, 입력 길이 구간, 배점. 영어(독해·듣기)는 언어를 통제한 비교 구간으로 따로 보고한다. 한국어 성능 자체도 측정 대상이므로 보정하지 않는다.

## 6. 채점 격리 (기존 `csat/` 원칙 유지)

20. 정답(`gold.json`)은 채점 단계에서만 읽는다. 어댑터와 실행기는 정답 파일을 import하지 않는다.
21. LLM 판정 없이 정해진 정답과 비교해서만 채점한다. 결과를 본 뒤 지시문·정본·어댑터를 바꾸면 새 버전으로 기록하고, 이전 결과와 섞지 않는다.

## 7. 첫 대상 `[결정]`

22. Jev(`jev-1.13.0`)는 확정이다. 복제본은 이 Mac Studio(M1 Max)에서 GPU 서버 없이 도는 것부터 시작한다. 각 README에서 실행 환경과 컨텍스트 길이를 확인한 뒤 고른다. 후보는 다음과 같다.
    - `jevmlx`, `open-jev (daseinlabs, MLX)`: MLX 기반
    - `SemIf`: Qwen3-0.6B Q8
    - `system-one`: TypeSafe 호환

